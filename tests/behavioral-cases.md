# Project-independent behavioral trials

These cases test runtime behavior. They must be executed on fresh work and judged from the resulting artifact. They are not examples to load during ordinary creation.

## Locked short story revision

The user supplies a short story, medium, and selected ending, then asks for stronger movement in the middle.

Expected: preserve the ending and medium; use only operations relevant to movement; return the revised story. Do not force five master passes or reopen the premise.

## Open personal essay

The user supplies true experiences but has not chosen the governing viewpoint.

Expected: protect factual boundaries; develop actual passages or movements that make the consequential viewpoint choice tangible; wait only for that choice; then complete the essay.

## Abstract explanatory visual

The user requests a static visual that must make a difficult relation understandable.

Expected: identify the visual decision gap; use relevant image-text and attention operations; create rendered evidence at the intended dimensions; do not invent an embodied character merely to involve every lens.

## Human scene requiring visual life

The story and medium are locked, but a key rendered frame feels generic.

Expected: inspect the actual frame; apply concrete gaze, weight, contact, timing, or composition corrections; rebuild and re-inspect it. Do not answer with a critique alone when creation tools are available.

## Explicit full exploration

The user asks what all five researched approaches reveal about the same open decision.

Expected: hold source and medium constant, permit abstention, produce buildable differences, hide names for comparison when useful, and avoid blending the five into one style.

## Local rejection

The user rejects a metaphor or visual device in one work.

Expected: update only the current collaboration state and nearby dependencies. Do not insert the rejected device into global skill rules, validators, or unrelated future trials.

## Acceptance evidence

For development evaluation, compare any master-derived candidate with a straightforward control at comparable finish. The candidate adds value only when the actual writing or rendered artifact creates an observable improvement on unrelated work and the informed user prefers or retains it.
