# Broad craft inquiry

Use this reference when the open decision is broad enough that several craft lenses could reveal materially different routes. Give every inquiry the same source, medium, audience, truth boundary, and open decision. Freeze a result before comparing it with another; do not let one proposal quietly become the premise of the next.

Do not run all eight by default. Start from the decision-gap router in [master-thinking-models.md](master-thinking-models.md). Use all eight only when the user explicitly requests every researched approach. Otherwise include only inquiries that can change the named decision.

The inquiries do not share a production template. Each follows the creator's documented decision process.

## Lynch inquiry

Start from a source fragment that already carries charge. Test whether it can generate a coherent relation, breach, clue path, recurrence, or unresolved remainder. Required facts must remain clear. Return a concrete narrative operation or abstain.

## Scorsese inquiry

Start from the intended human effect. Test viewpoint, inclusion and exclusion, order, transition, gesture, and what would be cut. Return a concrete attention-and-sequence proposal or abstain.

## McKean inquiry

Start from the relation among teller, tale, material, text, image, and reader. Test whether the medium can create a third meaning rather than decorate the copy. Return a concrete image-text or material proposal or abstain.

## Kurosawa inquiry

Start from the world state: actors, goals, information, constraints, environment, and equilibrium. Make the meaning move through motivated behavior, changing relations, tempo, and cuts. Return a concrete state-change proposal or abstain.

## Inoue inquiry

Start from the living core and the creator's present perspective. Test bodily or object truth, gaze, weight, timing, restraint, and the relationship between local correction and the whole. Return a concrete human or frame-level proposal or abstain.

## McPhee inquiry

Start from the factual units and their provenance. Test anchored versus movable material, competing organizing relations, research gaps, omission risk, and reader orientation. Return a concrete evidence structure or abstain.

## Niemann inquiry

Start from the communication job and a real observation in the source. Choose commissioned-backward or exploratory-hunch mode, test a truthful visual relation, specify the viewer's inference, and demand unprimed readback. Return a concrete visual concept or abstain.

## McCloud inquiry

Start from the reader change and delivery format. Test necessary moments, frame boundaries, image evidence, word responsibility, flow, disclosure, and the inference between units. Return a concrete sequence repair or abstain.

## What counts as a contribution

A contribution must produce a different audience experience or a buildable decision. It must also name its main risk. Atmosphere words, creator references, generic craft advice, or a lightly renamed version of another proposal do not count.

Only after the selected inquiries are frozen, translate viable results into a shared comparison: what each changes, what evidence it uses, what it risks, and what would have to be built or tested to judge it. Do not expose master names when they would bias the choice or distract from the work.
