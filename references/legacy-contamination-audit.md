# Legacy contamination audit

Read only when maintaining or testing this skill. Do not load this file during ordinary creation.

## Finding

The prior v2 package was not cleanly separated from the Gate 03 LinkedIn carousel used during development. Of 60 files shared with v1, 40 were byte-identical in the recovered packages. v2 added a council wrapper and new checks but retained the old medium modules, theory ledgers, and Gate 03 routing test.

## Critical event

The earliest unrecovered loss was the promotion of a production-specific representation and workflow assumptions into reusable method files. This is a memory/provenance contamination problem compounded by a self-referential evaluation artifact.

## Recovery test

Run an unrelated held-out story and frame task with the Gate 03 case unavailable. Fail if Gate 03 numbers, objects, palette, framework timing, or LinkedIn grammar appear without support from the new brief.

## Invalidation

This diagnosis would be weakened if an earlier, independent source were found for each supposedly leaked rule and unrelated held-out runs showed that the rule improves results without narrowing them. Until then, keep the historical case quarantined.
